# Contributing

Thanks for helping improve C4D Material Workflow Tools.

Useful contributions include:

- Cinema 4D / Redshift version compatibility reports.
- PBR filename patterns that are not detected correctly.
- Small reproducible test cases or filename examples.
- Bug fixes that preserve existing workflows.
- Documentation improvements.

## Bug reports

Please include:

1. Cinema 4D version.
2. Redshift version when the PBR builder is involved.
3. Which tool you used.
4. Minimal steps to reproduce the issue.
5. Relevant texture filenames or material/tag layout.
6. Console error text, if available.

## Pull requests

Keep changes focused. Avoid committing commercial assets, licensed texture packs, private project data or third-party code that cannot be redistributed.
